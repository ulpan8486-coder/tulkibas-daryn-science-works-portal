# TD Science Works Portal

Портал научных работ учеников школы **Tulkibas Daryn**. Ученики подают заявки с темами исследований, администраторы их принимают, а принятые работы автоматически попадают в архив текущего года.

Языки: қазақша / русский / English (переключатель справа вверху).

## Запуск

Нужен Node.js 18+. Внешние зависимости не нужны.

```bash
node server.js
```

Сайт откроется на http://localhost:3000.

При **первом** запуске создаётся файл `data/db.json` и учётная запись администратора. Почта и пароль администратора выводятся в консоль один раз. Можно задать свои:

```bash
ADMIN_EMAIL=admin@td.kz ADMIN_PASSWORD=СвойПароль node server.js
```

(на Windows PowerShell: `$env:ADMIN_PASSWORD="СвойПароль"; node server.js`)

Чтобы начать с чистой базы, остановите сервер и удалите папку `data/`.

## Хостинг (Render)

В репозитории есть `render.yaml`. На render.com выберите New → Blueprint → этот репозиторий и задайте `ADMIN_PASSWORD`. Каждый push в `main` обновляет сайт автоматически.

На бесплатном тарифе диск временный: после обновления или «засыпания» сервиса (15 минут без посетителей) база создаётся заново. Для постоянной работы нужен Render Disk (платный) или внешняя база данных.

## Логотип

Логотип школы лежит в `public/img/logo.png` (чтобы заменить, положите новый файл с тем же именем). Если файла нет, используется запасной `public/img/logo.svg`.

## Страницы

| Страница | Что там |
|---|---|
| `#/` | Описание сайта, логотип, кнопка «Начать» |
| `#/login`, `#/register` | Вход; регистрация (почта, имя, фамилия, класс 7–11, пароль) |
| `#/home` | Мероприятия с фильтром «Актуальные / Прошедшие / Все» |
| `#/submit` | Анкета: имя и фамилия, класс, мероприятие (список зависит от класса), заголовок, описание; справа «Мои заявки» |
| `#/archive` | Архив по годам: 2025 (работы и достижения), 2026 (текущий год, результаты позже) |
| `#/admin` | Только для админа: принять/отклонить заявки, управление мероприятиями |

Правила по классам: **Зерде** и **Эко Про** для 7–8 классов, **Общий конкурс** для 9–11. Админ может добавлять новые мероприятия и переносить их в «прошедшие».

Работы 2025 года добавляются вручную: админ → Архив → 2025 → «Добавить работу в архив». Результат можно изменить кнопкой «Изменить».

## Устройство

- `server.js`: HTTP-сервер и API (сессии через HttpOnly-cookie, пароли хешируются через scrypt), данные хранятся в `data/db.json`
- `public/index.html`, `app.js`, `styles.css`: одностраничное приложение
- `public/i18n.js`: все тексты интерфейса на трёх языках

Текущий год задаётся константой `CURRENT_YEAR` в `server.js`; годы архива задаются в `ARCHIVE_YEARS`.
