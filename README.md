# TD Science Works Portal

Портал научных работ учеников школы **Tulkibas Daryn**. Ученики подают заявки с темами исследований, администраторы их принимают, а принятые работы автоматически попадают в архив текущего года. На сайте также есть правила конкурсов и пробные тесты.

Языки: қазақша / русский / English (переключатель справа вверху).

## Запуск на компьютере

Нужен Node.js 18+.

```bash
npm install
node server.js
```

Сайт откроется на http://localhost:3000. Без `DATABASE_URL` данные хранятся в файле `data/db.json`.

При **первом** запуске создаётся учётная запись администратора `admin@td.kz`. Если пароль не задан, сервер один раз печатает случайный пароль в консоль. Свой пароль задаётся так:

```bash
ADMIN_PASSWORD=СвойПароль node server.js
```

(в Windows PowerShell: `$env:ADMIN_PASSWORD="СвойПароль"; node server.js`)

При каждом запуске пароль админа приводится к значению `ADMIN_PASSWORD`. Если вы забыли пароль, поменяйте переменную и перезапустите сервер.

## Переменные окружения

| Переменная | Зачем |
|---|---|
| `ADMIN_EMAIL` | почта администратора (по умолчанию `admin@td.kz`) |
| `ADMIN_PASSWORD` | пароль администратора |
| `DATABASE_URL` | строка подключения к Postgres. С ней данные не пропадают при перезапуске |
| `PORT` | порт (Render задаёт сам) |

## Хостинг (Render + Neon)

1. **База данных (бесплатно, бессрочно).** Зарегистрируйтесь на https://neon.tech, создайте проект и скопируйте *Connection string* (`postgresql://…neon.tech/…?sslmode=require`).
2. **Render** → сервис → *Environment*: добавьте `DATABASE_URL` с этой строкой и проверьте `ADMIN_PASSWORD`. Затем *Save, rebuild and deploy*.
3. В логах Render должна появиться строка `База данных: Postgres`.

Build Command: `npm install`, Start Command: `node server.js`. Каждый push в `main` обновляет сайт автоматически.

Без `DATABASE_URL` на бесплатном Render данные стираются при каждом перезапуске: в логах будет предупреждение.

## Страницы

| Страница | Кто видит | Что там |
|---|---|---|
| `#/` | все | Описание сайта, логотип, кнопки «Начать» и «Правила конкурсов» |
| `#/login`, `#/register` | все | Вход; регистрация (почта, имя, фамилия, класс 7–11, пароль) |
| `#/rules` | **все, без входа** | Краткие правила «Зерде», «ProEco» и общего конкурса (9–11) + скачивание PDF |
| `#/home` | ученики | Мероприятия с фильтром «Актуальные / Прошедшие / Все» |
| `#/submit` | ученики | Анкета: имя и фамилия, класс, мероприятие (зависит от класса), заголовок, описание; «Мои заявки» |
| `#/archive` | ученики | Архив по годам: 2025 (работы и достижения), 2026 (текущий год) |
| `#/tests` | ученики | Пробные тесты по 16 секциям: режимы «Экзамен» (2 часа) и «Тренировка», результат и разбор ошибок |
| `#/admin` | админ | Принять/отклонить заявки, управление мероприятиями |

Правила по классам: **Зерде** и **ProEco** для 7–8 классов, **Общий конкурс** для 9–11.

## Файлы с содержимым

- `public/rules.js`: краткое содержание правил (3 языка) и ссылки на документы
- `public/docs/*.pdf`: официальные правила (на казахском)
- `public/tests/section-XX.json`: вопросы тестов (60 вопросов на секцию, номер правильного ответа в `answer`, отсчёт с 0)
- `public/i18n.js`: все тексты интерфейса на трёх языках
- `public/img/logo.png`: логотип школы

## Устройство

- `server.js`: HTTP-сервер и API (сессии через HttpOnly-cookie, пароли хешируются scrypt). Всё состояние — один JSON-документ: в Postgres (таблица `app_state`) или в `data/db.json`.
- `public/index.html`, `app.js`, `styles.css`: одностраничное приложение.

Текущий год задаётся константой `CURRENT_YEAR` в `server.js`, годы архива — в `ARCHIVE_YEARS`.
